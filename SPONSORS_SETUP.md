# GitHub Sponsors Setup

The repository funding file is already configured:

```yaml
github: [Havys96]
```

That means the repository is ready to show a Sponsor link when the `Havys96` GitHub account is approved for GitHub Sponsors.

## Current Status

- `.github/FUNDING.yml` is published.
- The repository page exposes funding metadata.
- The public sponsors profile may still require account enrollment or approval.

## Finish Setup In GitHub

1. Sign in to GitHub as `Havys96`.
2. Open:

```text
https://github.com/sponsors/accounts
```

3. Start or complete GitHub Sponsors onboarding.
4. Complete any required profile, payout, tax, or identity steps.
5. After approval, open:

```text
https://github.com/Havys96/prediction-market-radar
```

6. Confirm the `Sponsor` button appears near the repository action buttons.

## Safe Funding Boundary

Use this wording:

```text
If this project saved you time, you can support open-source development.
Donations are optional and are not payment for trading signals, betting advice,
investment advice, order execution, restricted access, or profit-sharing.
```

Avoid:

```text
Support me if this helped you profit.
Donate for better signals.
Premium wallets or entries for sponsors.
Send me a share of your winnings.
```

## If GitHub Sponsors Is Not Available

Use one creator-support link instead:

```yaml
custom:
  - https://www.buymeacoffee.com/YOUR_NAME
```

or:

```yaml
ko_fi: YOUR_KOFI_NAME
```

Do not add a personal crypto wallet address for the first launch.
