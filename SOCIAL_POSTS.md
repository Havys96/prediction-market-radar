## X Thread

1/ I built Prediction Market Radar, an open-source local dashboard for prediction-market public data.

It is designed for research, not trading or betting automation.

Repo:
https://github.com/Havys96/prediction-market-radar

2/ Current v0.1.0 includes:

- active market dashboard
- Radar Score
- anomaly detector
- 15m/1h/24h probability history
- public large-trade observations
- wallet scorecards
- Wallet Alpha Ranking
- local alerts
- Markdown/HTML/CSV exports

3/ The boundary is intentional:

- no wallet connection
- no private keys
- no order execution
- no copy-trading
- no financial advice
- no betting advice
- no geo-bypass features

It is a public-data research dashboard.

4/ Why I built it:

Prediction-market research usually means jumping between market pages, wallet pages, leaderboards, trade feeds, and notes.

This compresses that review loop into one local dashboard.

5/ Feedback would help.

I am especially interested in:

- useful public data sources
- better scoring ideas
- UX issues
- what should be added next

Repo:
https://github.com/Havys96/prediction-market-radar

2. Post the short X post with the desktop screenshot.
3. Post the Instagram personal builder version with the desktop or mobile screenshot.
4. Wait 24 hours before posting to Reddit or Discord.
5. If someone asks whether it trades, reply with the safe read-only answer from `PUBLIC_LAUNCH_PACK.md`.
